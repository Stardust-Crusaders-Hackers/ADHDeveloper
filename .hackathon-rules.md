# Project Rules

1. **AGENT REGISTRATION RULE**: Any new agent added to this MCP server MUST be placed as a `.ts` file in `mcpServer/src/agents/` with a default export satisfying the `AgentDefinition` interface from `../types.js` (fields: `name: string`, `description: string`, `keywords: string[]`, `handler: (ctx: AgentContext) => Promise<AgentResult>`). The agent is auto-discovered at startup by the `AgentRegistry` — **NO manual registration needed**. Do NOT modify `index.ts` or the registry when adding a new agent.

2. **TOOL REGISTRATION RULE**: Utility tools that are NOT agents (no keywords, no orchestrator routing) go in `mcpServer/src/tools/` as named exports. They MUST be registered manually in `index.ts` via `server.tool(...)`. Use this for setup commands, integrations, and one-off utilities.
